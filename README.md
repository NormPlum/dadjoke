Dad Joke
========

Displays random Dad jokes from https://icanhazdadjoke.com/ in a block. A new
joke is retrieved on each cron run.


Installation
------------

- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.

- Add the 'Dad joke' block to a layout at Structure > Layouts
  (/admin/structure/layouts).
